# AI Fitness App

A comprehensive AI-powered fitness application built with React Native (Expo) and Node.js.

## Project Structure

- **/frontend**: React Native application built with Expo Router.
- **/backend**: Node.js / Express API specializing in AI workout recommendations and user activity tracking.

## Getting Started

### Prerequisites
- Node.js (v18+)
- Expo CLI
- Supabase account (for authentication and database)

### Backend Setup
1. `cd backend`
2. `npm install`
3. Configure `.env` with your Supabase credentials.
4. `npm run dev`

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npx expo start`

## Features
- User Authentication (Supabase)
- Activity Tracking
- AI Workout Recommendations
- Modern UI with Dark Mode support
